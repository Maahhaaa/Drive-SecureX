
# Simple CAN Flooding Simulator

A simple Python script that continuously transmits random CAN messages over a SocketCAN interface (`vcan0`). The script is intended for **testing**, **CAN Bus simulations**, and **Intrusion Detection System (IDS)** evaluation.

---

## Overview

This script creates a CAN bus object using the `python-can` library and repeatedly sends CAN frames with:

- Fixed CAN Identifier (`0x00`)
- Random 8-byte payload
- Standard CAN frame
- Maximum transmission rate (limited only by the operating system and CAN driver)

This can be used to simulate **high-frequency CAN traffic** or a simple **Denial-of-Service (DoS) attack** in a virtual CAN environment.

---

## Features

- Continuous CAN frame transmission
- Random payload generation
- Standard 11-bit CAN frames
- Uses SocketCAN (`vcan0`)
- Simple single-thread implementation

## Create a Virtual CAN Interface

Load the Virtual CAN kernel module

```bash
sudo modprobe vcan
```

Create the interface

```bash
sudo ip link add dev vcan0 type vcan
```

Enable the interface

```bash
sudo ip link set up vcan0
```

Verify

```bash
ip link show vcan0
```

## How It Works

The application performs the following steps repeatedly:

```text
Create CAN Frame
        │
        ▼
Generate Random 8-byte Payload
        │
        ▼
Assign CAN ID = 0x00
        │
        ▼
Transmit Frame to vcan0
        │
        ▼
Repeat
```

---

## CAN Frame Format

| Field | Value |
|--------|-------|
| CAN ID | `0x00` |
| Frame Type | Standard (11-bit) |
| DLC | 8 |
| Payload | Random bytes (0x00–0xFF) |

Example frame

```text
CAN ID : 0x00

DATA :
12 8F 45 AA 09 FF 31 C0
```

## Code Behavior

### Bus Initialization

Creates a SocketCAN interface.

```python
bus = can.interface.Bus(
    channel="vcan0",
    interface="socketcan"
)
```

---

### Random Payload

Each transmitted frame contains eight randomly generated bytes.

```python
[random.randint(0x00, 0xFF) for _ in range(8)]
```

---

### Transmission

Each generated frame is immediately transmitted.

```python
bus.send(msg)
```

---

### Delay

The script uses an extremely small sleep interval.

```python
time.sleep(0.000000000000000000000000000000000000000000000000000001)
```

In practice, this value is effectively treated as **zero** by the operating system. As a result, frames are transmitted as fast as the CPU, Python interpreter, and SocketCAN driver allow.
