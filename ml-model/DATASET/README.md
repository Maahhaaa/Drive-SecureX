# CAN-DSX Dataset

## 📌 Overview
CAN-DSX is a dataset generated from simulated CAN bus traffic using the **ICSIM simulator**.  
It is designed for cybersecurity research and machine learning applications such as anomaly detection in in-vehicle networks.

## 🧪 Data Source
The dataset is based on simulated vehicle CAN traffic generated using:
- ICSIM (Instrumented Car Simulation environment)

## 📂 Files
- dataset_formatted.part1.rar
- dataset_formatted.part2.rar

## 🎯 Use Cases
- Machine Learning
- Intrusion Detection Systems (IDS)
- CAN bus anomaly detection
- Automotive cybersecurity research
